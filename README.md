# HOLI-Lya
A repository containing the HOLI-Lya forest mocks code 

Set up a fresh environment at NERSC:
```
module load python
conda create -n holi-lya python=3.13
conda activate holi-lya
conda install numpy scipy numba h5py astropy healpy
```
